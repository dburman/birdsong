# Test fixtures

| File | Source | Notes |
|------|--------|-------|
| `soundscape_15s.wav` | First 15 s of `birdnet_analyzer/example/soundscape.wav` from [BirdNET-Analyzer](https://github.com/birdnet-team/BirdNET-Analyzer) (MIT-licensed repository) | 48 kHz, mono, 16-bit. 5 analysis chunks. |
| `soundscape_species_list.txt` | `birdnet_analyzer/example/species_list.txt`, same repo | Example custom species list. |
| `golden/soundscape_15s.json` | Generated by `tools/convert_model/export_reference.py` with `audio-model.tflite` (BirdNET V2.4 FP32) | Raw logits for every class and chunk. **Ground truth** for the Rust golden test. |
| `golden/soundscape_15s_chunk0_spec.f32` | Generated by `tools/convert_model/export_headless_v24.py` | TensorFlow output of the two mel layers for chunk 0, `(96, 511, 2)` float32 NHWC. Ground truth for the Rust mel frontend test. |

The full two-minute `soundscape.wav` and its `golden/soundscape.json` are ignored by git; if present
locally the golden test runs on them as well.

Regenerate everything with:

```bash
cd tools/convert_model
.venv/bin/python export_reference.py --model ../../models/audio-model.tflite --wav ../fixtures/soundscape_15s.wav --out ../fixtures/golden/soundscape_15s.json
.venv/bin/python export_headless_v24.py --wav ../fixtures/soundscape_15s.wav --golden ../fixtures/golden/soundscape_15s.json
```
